      jmp   Start

;====================================================================

;====================================================================

      org   0100h
Start:	
	SETB P1.0
	SETB P1.1
	NOP
	CLR P1.1
	NOP
	SETB P1.1
	CLR P1.0
	CLR P1.1
	NOP
	SETB P1.1
	NOP
Loop:	
      jmp Start

;====================================================================
      END

~~~

### 关于**汇编语言**
- **org**（伪指令）：设定下面代码存放的**单片机程序存储器地址**
	`org   0000h`
	把接下来的代码放在地址 0000h
- **jmp**：**无条件跳转指令**
	`jmp   Start`
	跳转到符号Start处执行代码
- **Start**，**Loop**：标号，把这一行起个名字，**标号后面带:**
- **SETB**：Set Bit，置1
	`SETB P1.0`
	把P1端口的第 0 位引脚P1.0设置为高电平 1
- **NOP**：空操作，等待1个机器周期
- **CLR**：Clear Bit，**清零**
	`CLR P1.1`
	将P1.1引脚设置为低电平 0
- **END**：伪指令，汇编文件结束标记
